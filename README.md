# 🛡️ UPI Shield AI
### Detect. Understand. Protect.

**UPI Shield AI** is an AI-based fraud awareness prototype designed to identify suspicious UPI messages, SMS and WhatsApp messages and help users stay safe from digital payment scams.

## 🚀 Features

- 🔍 Suspicious message scanner
- 📊 Fraud risk score (0–100)
- ⚠️ Risk level classification (LOW, MEDIUM, HIGH)
- 🧠 Explainable fraud warning signs
- 🌐 English, Tamil and Malayalam sample messages
- 🛡️ Safety recommendations
- 📋 Scan history
- 🧪 One-click sample testing

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. Open it in Chrome or Microsoft Edge.
5. Enter a suspicious message.
6. Click **Analyze Message** to view the results.

## 🎯 Project Objective

To create an accessible fraud-awareness tool that helps users identify suspicious financial messages, understand potential warning signs and make safer digital payment decisions.

## 🔮 Future Enhancements

- Machine learning-based fraud detection
- Screenshot-based scam detection
- Real-time fraud intelligence integration
- Improved multilingual detection
- Advanced fraud analytics dashboard

## ⚠️ Disclaimer

This is an educational prototype. It does not connect to banks, verify actual UPI transactions or guarantee fraud detection. Always verify suspicious payment requests through official channels.
